Title: Create and Edit Articles

User Story:
As a content creator, I want to create and edit articles within the platform so that I can publish and manage my content easily.

Acceptance Criteria:
- User can navigate to a "New Article" page from the dashboard.
- User can enter a title, body content, and optional tags.
- User can save an article as a draft.
- User can publish an article.
- User can edit an existing article.
- Changes are saved and reflected immediately after publishing.
- Validation errors are shown if required fields (e.g., title, body) are missing.

Notes:
- Use existing form components and styling patterns in the app.
- Persist article data via the current API service layer.
- Ensure responsive layout for both desktop and mobile.
